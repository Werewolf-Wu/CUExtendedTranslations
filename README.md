# About Data Source
`buildings.yaml` is generated by a python script reading the result of
[Asset Ripper](https://github.com/AssetRipper/AssetRipper).
(I'm rewriting that with [UnityPy](https://github.com/K0lb3/UnityPy) and uv)

`recipes.yaml` is generated by a python script reading the decompiled code.

`liquids.yaml`, `sources.yaml`, `items.yaml` is generated by a complex Beplnex plugin.

I tried to write a Beplnex plugin to dump all data at first,
it actually works well,
but then I found it's too unstable and hard to maintain
such a project during the game version changes
as it contains a lot of probe and IL readers.
And it makes CI/CD painful as we don't hold the copyright of the game source code.
So, if you want to make a mod like that, please consider this point.
